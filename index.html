An open platform for sharing Wi-Fi access

People and venues share free or open Wi-Fi, so that other people can find it and join it. The data is public and openly licensed. The code is open source.

Status: early development WiFiShare started in September 2026. No data has been collected and none has been published. No app has been released. The API is not live, and the address in the API specification is a placeholder. What exists today is the specification, the empty data repository and this site.

The three privacy rules

These come before features. Every rule in the specification exists to serve one of them.

  1. Collect only what helps someone connect. A network name, whether it is open, whether there is a captive portal, and roughly where it is. Nothing about the person who saw it.
  2. Publish less than is collected. A network that someone's app saw while walking past is published as a name inside a cell about 150 m across, without its hardware address.
  3. Keep nothing that ties an observation to a person. No accounts, no device identifiers, no advertising identifiers. Raw observations are deleted within 7 days of the aggregation that used them.

How it will work

  1. The app filters on the phone. Networks that must not be collected are dropped before anything is stored or sent: hidden networks, names ending in _nomap or _optout, phone hotspots, and anything that is not open.
  2. What survives is encrypted and sent in a batch. The batch is encrypted to the server's key before it leaves the phone, and carries no identifier, no sequence number and no timestamp of its own.
  3. The server aggregates and applies thresholds. A network is published only after at least 3 observations, from at least 3 different sources, on at least 2 different days.
  4. The result is published as open data. Area files on the API and a weekly dump on GitHub, under the Open Database License.
  5. Venues can claim their own network. A venue that wants to be found exactly proves it controls the network and chooses what to share.

What it is not

  • It is not a positioning database. There is no way to ask where a given access point is: community-found hardware addresses are never published, and the API has no lookup by hardware address.
  • It is not a way to get into networks that are not being shared. Password-protected networks are collected only when their owner shares them deliberately.
  • It is not a product with users, partners or a launch date. It is a specification and some empty repositories.
