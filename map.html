Map

This is sample data. None of these networks exist. WiFiShare has published nothing yet: the dump is empty and the API is not live. So that the map can be built and reviewed, it is drawing five invented networks in one area over the centre of Bologna. Every name starts with SAMPLE. To point the map at real data, set DATA_BASE_URL in config.js.

How to read it

What the two kinds of network look like
Kind On the map What the position means
Community-found A small dot inside a dashed square The square is the geohash-7 cell, about 150 m across. The network is somewhere in it. The dot is the centre of the square and is not a measurement.
Owner-verified A larger dot with no square The venue asked to be found, so the position is exact, published with a stated precision of 10 m, and the hardware addresses are published too.

Every network is also listed below in words, with the same detail, so the map is not the only way to read the page. Kind is written out there rather than shown by colour.

    Where the data comes from

    The map reads the dump layout directly. It asks for index.json first, to learn which areas exist, and then for one file per visible area:

    <DATA_BASE_URL>/index.json
<DATA_BASE_URL>/areas/<gh2>/<gh3>/<gh5>.geojson

    With no DATA_BASE_URL configured it falls back to sample/ in this repository and says so in the banner above. An area with no file is not an error: it means nothing is published there, and the map says so rather than showing an empty map with no explanation.

    When the map is zoomed out past the point where the number of area files is reasonable, it stops asking for them and says to zoom in. An area file covers about 4.9 km.

    What the map deliberately does not do

    • It does not ask for your location. Nothing on this site does.
    • It does not send your position anywhere. Area files are fetched by cell name, and a cell is about 4.9 km across.
    • It sets no cookies and loads no analytics. The map library comes from a public CDN and the background tiles from the provider named above; those are the only third-party requests on this site, and they happen only on this page.
